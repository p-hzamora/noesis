# Code of Conduct

We want noesis to be a welcoming project for everyone, whatever their experience,
background, or identity.

## Our standards

Expected:

- Be respectful and assume good intent.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and the people using it.

Not acceptable:

- Harassment, insults, or personal attacks.
- Discriminatory language or imagery.
- Publishing someone else's private information.
- Trolling, or any conduct that would be inappropriate in a professional setting.

## Scope

This applies in all project spaces (issues, pull requests, discussions) and when
someone represents the project in public.

## Enforcement

Report unacceptable behavior privately through GitHub's "Report abuse" on the content or
by contacting the maintainer via the email on their GitHub profile. Maintainers will review
reports promptly and may edit or remove comments, lock threads, or block contributors to
keep the space safe.

This Code of Conduct is adapted from the
[Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
